# 永恒之塔2 智能辅助系统

一个功能完整的永恒之塔2（Aion 2）游戏辅助工具，支持自动Farm、智能拾取、技能轮转和背包管理等功能。

**本工具仅供学习和研究使用。使用游戏辅助工具可能违反游戏服务条款，导致账号封禁。使用本工具造成的任何后果由用户自行承担。**

## ✨ 功能特性

### 🎮 角色管理
- 实时显示角色状态（等级、经验、血量、法力）
- 支持多职业选择（剑星、魔道星、弓星、护星、杀星）
- 自动状态监控和恢复

### ⚔️ 自动战斗系统
- **自动搜索敌人**：可配置搜索范围（10-100米）
- **智能目标选择**：
  - 最近的敌人
  - 最低血量优先
  - 最高等级优先
  - 精英怪优先
- **自动攻击**：持续攻击直到目标死亡
- **自动休息**：血量低于阈值时自动休息恢复
- **自动使用药水**：危急时刻自动使用生命药水

### ✨ 技能轮转系统
- 支持6个技能槽位配置
- 可调节技能释放延迟（100-2000毫秒）
- 智能法力管理，避免法力耗尽
- 可设置保留法力百分比

### 💎 自动拾取系统
- **智能范围拾取**：可配置拾取范围（5-50米）
- **品质过滤**：
  - 普通（白色）
  - 稀有（绿色）
  - 史诗（紫色）
  - 传说（橙色）
- **自动拾取金币和材料**
- **掉落物品实时追踪**

### 🎒 背包管理系统
- **背包可视化**：36格背包预览
- **自动清理**：达到阈值自动清理低品质物品
- **自动整理**：按品质排序整理背包
- **自动出售**：自动出售垃圾物品（功能预留）
- **实时容量监控**：背包使用率进度条显示

### 📊 统计系统
- 击杀数统计
- 拾取物品数量
- 经验获取追踪
- 金币获取统计
- 运行时长记录

### 🎛️ 控制面板
- 一键启动/停止
- 暂停/继续功能
- 配置保存/加载
- 实时日志查看
- 日志导出功能

## 📖 详细使用说明

### 1. 初始配置

首次使用时，建议按以下步骤配置：

1. **选择职业**：在"角色状态"面板选择你的游戏职业
2. **配置战斗**：
   - 勾选"启用自动战斗"
   - 设置搜索范围（推荐30米）
   - 选择目标优先级
   - 设置休息和药水阈值
3. **配置技能**：
   - 勾选"启用自动技能"
   - 点击技能槽激活要使用的技能
   - 设置技能释放延迟
4. **配置拾取**：
   - 勾选"启用自动拾取"
   - 设置拾取范围
   - 选择要拾取的物品品质
5. **配置背包**：
   - 勾选"自动清理背包"
   - 设置清理阈值（推荐80%）

### 2. 启动系统

点击"▶️ 启动系统"按钮，或按 **F1** 快捷键启动。

系统启动后会自动：
- 搜索附近敌人并攻击
- 使用配置的技能轮转
- 拾取掉落物品
- 管理背包空间
- 在需要时休息或使用药水

### 3. 快捷键

| 快捷键 | 功能 |
|--------|------|
| **F1** | 启动/停止系统 |
| **F2** | 暂停/继续 |
| **F3** | 立即清理背包 |
| **F4** | 紧急停止 |

### 4. 保存配置

点击"💾 保存配置"按钮保存当前所有设置。

配置会保存到浏览器的本地存储（localStorage），下次打开页面会自动加载。

### 5. 监控运行状态

- **状态指示灯**：绿色表示运行中，灰色表示停止
- **实时日志**：查看系统运行日志
- **统计面板**：查看击杀、拾取等统计数据
- **背包预览**：实时查看背包物品

## ⚙️ 配置说明

### 战斗配置

- **搜索范围**：怪物搜索半径，范围越大消耗越多
- **目标优先级**：
  - 最近的敌人：快速清理周围怪物
  - 最低血量：优先击杀残血怪物
  - 最高等级：获取更多经验
  - 精英怪优先：优先击杀精英获取好装备
- **休息阈值**：血量低于此值时休息
- **药水阈值**：血量低于此值时使用药水

### 技能配置

- **技能延迟**：两次技能之间的间隔时间
- **法力管理**：启用后会预留一定法力值

### 拾取配置

- **品质过滤**：只拾取选中品质的物品
- **拾取范围**：物品拾取半径

### 背包配置

- **清理阈值**：背包使用率达到此值时自动清理
- **自动出售**：清理时是否自动出售（需要在商店附近）

## 🛠️ 二次开发

本工具采用纯JavaScript开发，代码结构清晰，易于修改和扩展。

主要类和方法：

```javascript
class Aion2Assistant {
    start()           // 启动系统
    stop()            // 停止系统
    combatUpdate()    // 战斗循环
    lootUpdate()      // 拾取循环
    cleanInventory()  // 清理背包
    saveConfig()      // 保存配置
    // ... 更多方法
}
```

要添加新功能，只需：
1. 在对应的update函数中添加逻辑
2. 在UI中添加控制元素
3. 在saveConfig/loadConfig中添加配置项
