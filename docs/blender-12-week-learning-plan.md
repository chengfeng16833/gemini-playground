# 🗓️ Blender 12 周学习计划（零基础 → 完整动画作品）

> 节奏建议：每周约 **10-15 小时**（工作日各 1.5h + 周末 5h）。时间不够就把每阶段拉长 1.5 倍，按 18 周走也完全 OK。
> 用法：完成一项就把 `[ ]` 改成 `[x]`，在 GitHub 上追踪进度 ✅

---

## 📦 第一阶段：地基 + 建模（第 1-4 周）

### 第 1 周｜熟悉 Blender + 走完第一个完整流程
- 目标：摸熟界面、导航、快捷键，体验"建模→材质→灯光→渲染"全流程
- 学什么：视图导航、G/R/S、物体/编辑模式、保存与渲染
- 资源：⭐ Blender Guru「甜甜圈教程」(Donut) 全集
- [ ] 看完甜甜圈教程
- [ ] **产出：一个渲染好的甜甜圈图**

### 第 2 周｜建模基础操作
- 目标：掌握核心建模工具
- 学什么：挤出(E)、内插(I)、倒角(Ctrl+B)、循环切(Ctrl+R)、镜像/细分修改器
- 资源：Grant Abbitt 建模入门系列
- [ ] 学完核心建模工具
- [ ] **产出：3 个简单道具（杯子 / 椅子 / 宝箱）**

### 第 3 周｜低多边形场景
- 目标：组合多个模型成小场景，练手感和构图
- 学什么：物体组织、集合、简单材质上色
- 资源：Imphenzia「10 分钟低多边形」挑战 ×5 + Grant Abbitt 低多边形场景
- [ ] 完成 5 个 10 分钟低多边形挑战
- [ ] **产出：一个低多边形小场景（小岛 / 房间 / 街角）**

### 第 4 周｜布线 + UV 展开（关键基本功）
- 目标：理解好布线，学会 UV 展开
- 学什么：拓扑基础、Mark Seam、UV Unwrap、棋盘格检查拉伸
- 资源：Grant Abbitt UV 教程、Blender 官方手册 UV 章节
- [ ] 理解拓扑与布线
- [ ] **产出：给第 3 周场景做好 UV**
- 🏁 里程碑：能独立建模一个干净小场景并展好 UV

---

## 🎨 第二阶段：材质贴图 + 渲染（第 5-7 周）

### 第 5 周｜材质与节点
- 目标：看懂 Shader 节点，做出 PBR 材质
- 学什么：Principled BSDF、金属度/粗糙度、法线贴图、节点连接
- 资源：Blender Guru 材质教程、Poly Haven 免费材质
- [ ] 掌握 Shader 节点基础
- [ ] **产出：给场景所有物体上好真实材质**

### 第 6 周｜纹理绘制 + 程序化材质
- 目标：会手绘贴图 + 用节点程序化生成材质
- 学什么：Texture Paint、Noise/Voronoi 程序化节点
- 资源：Default Cube / Ryan King Art 程序化材质系列
- [ ] 学会纹理绘制
- [ ] **产出：一个手绘贴图道具 + 一个程序化材质**

### 第 7 周｜灯光与渲染
- 目标：会打光、用相机构图、出高质量渲染
- 学什么：Cycles vs Eevee、HDRI、三点布光、景深、降噪、基础合成
- 资源：⭐ Blender Guru 灯光教程 + Gleb Alexandrov 灯光技巧
- [ ] 掌握三点布光与相机
- [ ] **产出：一张作品级静帧渲染图**
- 🏁 里程碑：能产出可放进作品集的静帧

---

## 🎬 第三阶段：动画（第 8-12 周，重点）

### 第 8 周｜关键帧动画基础
- 目标：理解关键帧、时间轴、曲线编辑器
- 学什么：插入关键帧、Graph Editor、缓动、动画 12 原则
- 资源：Blender 官方动画入门 +《Animator's Survival Kit》
- [ ] 理解关键帧与 12 原则
- [ ] **产出：弹跳球动画**

### 第 9 周｜骨骼绑定基础
- 目标：理解骨架和权重
- 学什么：Armature、父子级、权重绘制、IK/FK 概念
- 资源：⭐ Pierrick Picaut (P2design) 绑定教程、Joey Carlino
- [ ] 学会绑骨与权重绘制
- [ ] **产出：给一个角色（或机械臂）绑好骨骼并摆姿势**

### 第 10 周｜角色动画：走路循环
- 目标：做出经典走路循环（行业入门基准）
- 学什么：Walk Cycle 关键姿势、循环、重心
- 资源：Sir Wade / P2design 走路循环教程
- [ ] 掌握走路循环
- [ ] **产出：一段循环走路动画**

### 第 11 周｜Mixamo 加速 + 物理模拟
- 目标：学会用现成动作 + 体验物理动画
- 学什么：Mixamo 自动绑骨+套动作、布料/刚体模拟
- 资源：Mixamo 官方 + Blender 物理教程
- [ ] 用 Mixamo 套动作
- [ ] **产出：一个 Mixamo 动作角色 + 一个布料/碰撞演示**

### 第 12 周｜整合：完整短片
- 目标：把所有技能串起来产出作品
- 学什么：场景+角色+动画+灯光+运镜+渲染序列+合成输出
- 资源：复习全部 + Blender Studio 开源工程参考
- [ ] 整合所有技能
- [ ] **产出：一段 5-15 秒完整动画短片** 🎉
- 🏁 最终里程碑：一个能放进作品集的完整动画短片

## 🎁 免费资源库（收藏）

**视频教程**
- Blender Guru — 入门必看（甜甜圈、材质、灯光）
- Grant Abbitt — 最适合新手的建模教学
- Imphenzia — 10 分钟低多边形练手
- Pierrick Picaut (P2design) — 绑定与动画
- Joey Carlino — 角色全流程
- Default Cube / Ryan King Art — 节点与程序化材质
- Gleb Alexandrov (Creative Shrimp) — 灯光渲染
- Sir Wade Neistadt — 动画职业向

**免费素材（CC0 可商用）**
- Poly Haven — HDRI / 材质 / 模型
- ambientCG — PBR 材质
- BlenderKit 免费区 — 资产

**官方 & 社区**
- Blender 官方手册 docs.blender.org（有中文）
- Blender Studio — 官方开源电影工程文件
- Mixamo — 免费自动绑骨 + 人形动作库
- Blender Artists 论坛 / r/blender — 提问找灵感

**书**
- 《The Animator's Survival Kit》（动画师生存手册）— 动画圣经

## 💡 使用建议
- 固定节奏比突击有效：每周排好时间
- 重产出轻完美：每周作品做完就发出去，逼自己收尾
- 卡住别死磕：超过 30 分钟解决不了就搜索/上论坛
- 每个阶段都产出一个能进作品集的小作品
